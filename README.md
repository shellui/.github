# .github

Shared GitHub files for the [Shellui](https://github.com/shellui) organization.

| Path | What it does |
| --- | --- |
| [`profile/README.md`](profile/README.md) | The page shown on [github.com/shellui](https://github.com/shellui) |

Community files placed at the root of this repository, such as `CONTRIBUTING.md`, `SECURITY.md` or issue templates, become the default for every Shellui repository that has none of its own. See [GitHub's documentation](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).
